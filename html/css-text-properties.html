CSS 텍스트 속성 가이드

font · color · text-shadow · direction · decoration · transform — 10가지 예제

01

font-size — 글자 크기

font-size

텍스트의 크기를 지정합니다. px(고정), em(부모 기준 배율), rem(루트 기준) 단위를 주로 사용합니다. 반응형 디자인에서는 rem 또는 % 단위 사용을 권장합니다.

12px 작은 텍스트   18px 중간 텍스트   28px 큰 텍스트
font-size: 12px / 18px / 28px
02

font-weight — 글자 굵기

font-weight

텍스트의 굵기를 설정합니다. 100~900 숫자 또는 normal(400), bold(700) 키워드를 사용합니다. 폰트에 따라 지원되는 굵기 단계가 다를 수 있습니다.

300 · Light — 가벼운 텍스트

400 · Normal — 기본 텍스트

700 · Bold — 굵은 텍스트

font-weight: 300 / 400 / 700
03

color — 텍스트 색상 (16진수)

color: #RRGGBB

텍스트 색상을 16진수(HEX)로 지정합니다. #RRGGBB 형식이며 각 쌍은 빨강·초록·파랑(0~FF)을 나타냅니다. #fff처럼 3자리 축약도 가능합니다.

#c0392b #2980b9 #27ae60 #f39c12 #8e44ad
color: #c0392b / #2980b9 / #27ae60
04

text-shadow — 텍스트 그림자

text-shadow

텍스트에 그림자 효과를 줍니다. 값의 순서는 수평 수직 흐림 색상입니다. 콤마(,)로 여러 그림자를 중첩하면 네온, 엠보스 등 다양한 효과를 만들 수 있습니다.

기본 그림자 효과 네온 글로우 효과 엠보스 효과
text-shadow: 2px 2px 4px #aaaaaa text-shadow: 0 0 8px #2980b9, 0 0 20px #2980b9
05

direction — 텍스트 방향

direction

텍스트 흐름 방향을 지정합니다. ltr(left-to-right, 기본값)은 한국어·영어처럼 왼쪽→오른쪽, rtl(right-to-left)은 아랍어·히브리어처럼 오른쪽→왼쪽 방향입니다.

ltr: 왼쪽에서 오른쪽 → (한국어·영어 기본)
rtl: ← 오른쪽에서 왼쪽 (아랍어·히브리어)
direction: ltr /* 기본값 */ direction: rtl /* 우→좌 */
06

text-decoration — 텍스트 꾸밈선

text-decoration

텍스트에 밑줄, 윗줄, 취소선 등을 추가합니다. underline(밑줄), overline(윗줄), line-through(취소선), none(제거)을 사용하며 색상과 스타일도 함께 지정할 수 있습니다.

underline — 파란 밑줄 overline — 초록 윗줄 line-through — 빨간 취소선 underline wavy — 물결 밑줄
text-decoration: underline #2980b9 text-decoration: underline wavy #f39c12
07

text-transform — 대소문자 변환

text-transform

HTML 원본을 수정하지 않고 CSS만으로 텍스트 대소문자를 변환합니다. uppercase(전체 대문자), lowercase(전체 소문자), capitalize(첫 글자만 대문자) 값을 사용합니다.

none: hello world css uppercase: hello world css lowercase: HELLO WORLD CSS capitalize: hello world css
text-transform: uppercase / lowercase / capitalize
08

font-style — 기울임 스타일

font-style

텍스트를 기울여 표시합니다. italic은 폰트에 내장된 이탤릭체를, oblique는 일반 글꼴을 강제로 기울인 형태를 사용합니다. 인용문이나 강조 문구에 자주 활용됩니다.

normal — 일반 텍스트 italic — 이탤릭체 기울임 oblique — 강제 기울임
font-style: normal / italic / oblique
09

letter/word-spacing — 자간·어간

letter-spacing

letter-spacing은 글자 사이 간격(자간), word-spacing은 단어 사이 간격(어간)을 조절합니다. 양수는 간격을 넓히고, 음수는 좁힙니다. 헤딩이나 로고 텍스트에 자주 사용됩니다.

letter-spacing: -1px 좁은자간 letter-spacing: 3px 넓은자간 word spacing 12px 어간넓힘
letter-spacing: 3px word-spacing: 12px
10

line-height — 행간 (줄 높이)

line-height

줄 사이 간격(행간)을 조절합니다. 숫자(배율), px, %로 지정할 수 있으며 단위 없는 숫자(예: 1.8)가 권장됩니다. 가독성 좋은 본문 텍스트는 보통 1.6~1.8을 사용합니다.

line-height: 1.0

줄 간격이 매우 좁아 텍스트가 빼곡하게 붙어있는 상태입니다.

line-height: 2.0

줄 간격이 넓어 텍스트가 여유롭고 읽기 편한 상태입니다.

line-height: 1.0 /* 좁음 */ line-height: 2.0 /* 넓음, 권장: 1.6~1.8 */
