경계선 (Border) border: 굵기 종류 색상

solid 실선

가장 기본적인 경계선. 끊김 없는 실선으로 표시됩니다.

solid border
border: 3px solid #2563a8;

dashed 파선

일정 간격으로 끊긴 대시(—) 형태의 경계선입니다.

dashed border
border: 3px dashed #d04f2e;

dotted 점선

작은 점(•)이 이어지는 경계선. 섬세한 구분선에 활용됩니다.

dotted border
border: 3px dotted #1e8a4c;

double 이중선

두 줄의 실선으로 이루어진 경계선. 굵기가 5px 이상이어야 잘 보입니다.

double border
border: 5px double #7c3aed;

groove / ridge 입체선

groove는 파인 느낌, ridge는 튀어나온 느낌의 3D 경계선입니다.

groove
ridge
border: 4px groove #c27d10; border: 4px ridge #2563a8;

inset / outset 눌린·솟은

inset은 요소가 눌린 듯, outset은 솟아오른 듯한 3D 효과입니다.

inset
outset
border: 4px inset #d04f2e; border: 4px outset #1e8a4c;

방향별 개별 지정 top/right/bottom/left

각 방향에 서로 다른 경계선 종류와 색상을 독립적으로 지정할 수 있습니다.

방향별 혼합 border
border-top: 3px solid #2563a8; border-right: 3px dashed #d04f2e; border-bottom: 3px dotted #1e8a4c; border-left: 4px double #7c3aed;

border-radius 모서리 둥글기

경계선 모서리를 둥글게 만듭니다. 50%로 설정하면 원형이 됩니다.

radius: 20px
50%
border-radius: 20px; /* 둥근 모서리 */ border-radius: 50%; /* 원형 */

border: none / 0 경계선 제거

기본 스타일을 초기화하거나 특정 방향 경계선만 제거할 때 사용합니다. 버튼·입력창 초기화에 자주 씁니다.

border: none
border-bottom only
border: none; border-bottom: 2px solid #1c1c1a;
Margin · Padding 요소 바깥 여백 · 안쪽 여백

Margin — 바깥 여백 요소 외부

요소와 요소 사이의 바깥 공간을 만듭니다. 배경색이 적용되지 않으며, 인접 margin은 겹쳐집니다(margin collapse).

부모 요소
margin: 14px
(모든 방향 14px 여백)
margin: 14px; /* 전체 */ margin: 10px 20px; /* 상하 좌우 */ margin: 5px 10px 15px 20px; /* 상 우 하 좌 */ margin-top: 20px; /* 위만 */ margin: 0 auto; /* 수평 가운데 정렬 */

Padding — 안쪽 여백 요소 내부

요소의 테두리와 내용 사이의 안쪽 공간을 만듭니다. 배경색이 적용되며 요소의 실제 크기에 영향을 줍니다.

padding: 20px
콘텐츠 영역
padding: 20px; /* 전체 */ padding: 10px 24px; /* 상하 좌우 */ padding: 4px 8px 12px 16px; /* 상 우 하 좌 */ padding-left: 16px; /* 왼쪽만 */

Margin 단축 표기법 shorthand

값의 개수에 따라 적용 방향이 달라집니다. 시계 방향(상→우→하→좌) 순서로 기억하세요. Padding도 동일한 규칙을 따릅니다.

margin: 8px → 상하좌우 동일
margin: 8px 16px → 상하 8 / 좌우 16
margin: 4px 8px 12px 16px → 개별
/* 값 1개: 상하좌우 동일 */ margin: 8px; /* 값 2개: 상하 / 좌우 */ margin: 8px 16px; /* 값 3개: 상 / 좌우 / 하 */ margin: 4px 16px 12px; /* 값 4개: 상 우 하 좌 */ margin: 4px 8px 12px 16px;

Margin vs Padding 비교 차이점

두 속성의 핵심 차이: margin은 요소 밖, padding은 요소 안. 배경색 적용 여부와 클릭 영역에 영향을 줍니다.

margin(파란 배경 밖) + padding(안쪽 공간)
/* margin: 배경 적용 ✗, 여백 겹침 발생 */ margin: 16px; /* padding: 배경 적용 ✓, 클릭 영역 포함 */ padding: 16px;
Box Model · Box Shadow box-sizing · box-shadow

box-sizing: content-box 기본값

width/height가 콘텐츠 영역만 포함. padding과 border가 추가되어 실제 크기가 커집니다.

콘텐츠
100×50 + padding + border
box-sizing: content-box; width: 100px; /* 실제: 130px */ padding: 10px; border: 5px solid #7c3aed;

box-sizing: border-box 권장

width/height가 border까지 포함한 전체 크기. padding을 줘도 지정 크기를 유지해 레이아웃이 예측 가능합니다.

border-box
width 그대로 100px
box-sizing: border-box; width: 100px; /* 실제: 100px */ padding: 10px; border: 5px solid #d04f2e;

기본 그림자 box-shadow

수평·수직 오프셋, 흐림(blur), 색상을 지정하는 가장 일반적인 그림자입니다.

기본 그림자
/* x y blur color */ box-shadow: 4px 4px 8px #aaaaaa;

spread — 테두리 확산 윤곽선 효과

네 번째 값(spread)으로 그림자를 모든 방향으로 균등하게 확장합니다. 테두리처럼 활용됩니다.

spread shadow
/* x y blur spread color */ box-shadow: 0 0 0 4px #2563a8;

inset — 내부 그림자 눌린 효과

inset 키워드를 앞에 붙이면 그림자가 요소 안쪽으로 들어갑니다. 눌린 버튼이나 오목한 인풋에 사용합니다.

inset shadow
box-shadow: inset 4px 4px 10px #aaaaaa;

다중 그림자 콤마로 중첩

콤마(,)로 여러 그림자를 겹쳐 레이어링 효과를 만듭니다. 오프셋 그림자를 중첩하면 만화 스타일 효과를 낼 수 있습니다.

multi shadow
box-shadow: 4px 4px 0 #c27d10, 8px 8px 0 #d04f2e;

부드러운 그림자 카드 UI

blur 값을 크게, 색상을 반투명하게 주면 자연스럽고 입체적인 카드 그림자 효과를 만들 수 있습니다.

soft shadow
box-shadow: 0 10px 30px rgba(0,0,0,0.12);

하드 그림자 플랫 디자인

blur 없이 오프셋만 주면 선명하고 경쾌한 플랫 그림자가 만들어집니다. 현대적인 UI 디자인에 많이 쓰입니다.

hard shadow
box-shadow: 6px 6px 0 #1c1c1a;

box-shadow 문법 정리 전체 구조

총 6개의 값으로 구성. inset과 spread는 생략 가능. 콤마로 여러 그림자를 나열할 수 있습니다.

inset? offset-x offset-y blur? spread? color
/* 기본 */ box-shadow: 2px 4px 8px #ccc; /* 전체 */ box-shadow: inset 2px 4px 8px 2px rgba(0,0,0,.2); /* 제거 */ box-shadow: none;
