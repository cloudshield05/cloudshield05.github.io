웹 스타일링의 핵심, CSS 선택자 6가지를 예제와 함께 완전히 이해합니다.

목차

01

전체 선택자

* { }

별표(*)를 사용하며, HTML 문서 내의 모든 요소를 동시에 선택합니다. 주로 브라우저 기본 스타일을 초기화하는 CSS Reset 또는 Normalize에 사용됩니다. 적용 범위가 매우 넓어 과도하게 사용하면 성능에 영향을 줄 수 있으므로 주의가 필요합니다.

브라우저 초기화 box-sizing 통일 전역 폰트 설정
style.css 
/* 전체 선택자: 모든 요소에 적용 */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
  font-family: Georgia, serif;
  color: #2a6496;
}
미리보기
✅ 이 박스 안의 모든 요소에 동일한 스타일이 적용되었습니다. margin, padding이 0으로 초기화되고, 같은 폰트와 색상을 공유합니다.
02

클래스 선택자

.className { }

점(.) 뒤에 클래스 이름을 적어 선택합니다. HTML에서 class="이름" 속성을 가진 요소를 선택하며, 여러 요소에 동일한 클래스를 부여할 수 있어 재사용성이 가장 높습니다. 하나의 요소에 여러 클래스를 동시에 적용하는 것도 가능합니다.

재사용 가능 다중 클래스 적용 가장 일반적
style.css 
/* 클래스 선택자: .클래스명 */
.highlight-yellow {
  background: #fff176;
  padding: 2px 6px;
  border-radius: 3px;
}

.highlight-green {
  background: #c8e6c9;
  padding: 2px 6px;
}

/* HTML: <span class="highlight-yellow">텍스트</span> */
미리보기

CSS에서 클래스 선택자는 가장 많이 쓰이며, 재사용이 자유롭고, 여러 클래스를 조합할 수도 있습니다.

03

ID 선택자

#idName { }

샵(#) 뒤에 ID 이름을 적어 선택합니다. HTML에서 id="이름" 속성으로 지정하며, 한 페이지에 동일한 ID는 단 하나만 존재해야 합니다. 특이성(specificity)이 클래스보다 높아 스타일 우선순위가 높지만, 남용하면 유지보수가 어려워집니다.

페이지당 고유 1개 높은 우선순위 앵커 링크 활용
style.css 
/* ID 선택자: #아이디명 */
#demo3-box {
  background: #1a1a18;
  color: #f5f2eb;
  padding: 16px 20px;
  border-left: 4px solid #c84b2f;
  border-radius: 8px;
}

/* HTML: <div id="demo3-box">...</div> */
미리보기
이 요소는 #demo3-box ID를 가진 유일한 요소입니다. ID는 페이지 내에서 한 번만 사용되어야 하며, 앵커 링크(#demo3-box)로도 활용됩니다.
04

자식 선택자

부모 > 자식 { }

꺽쇠(>)를 사용하며, 지정한 부모 요소의 직계 자식만 선택합니다. 손자나 그 이하 요소는 선택되지 않아 스타일 범위를 정밀하게 제어할 수 있습니다. 공백( )으로 연결하는 후손 선택자와 구별하는 것이 중요합니다.

직계 자식만 선택 정밀한 범위 제어 네비게이션에 유용
style.css 
/* 자식 선택자: 부모 > 직계자식만 */
.nav > a {
  color: #f5f2eb;
  background: rgba(255,255,255,0.08);
  padding: 6px 14px;
  border-radius: 6px;
}

/* .nav 안의 <span> 속 <a>는 선택 안 됨! */
미리보기
홈 서비스 포트폴리오 문의 ← 직계 <a>만 스타일 적용됨 (중첩 링크는 미적용)
05

속성 선택자

요소[속성="값"] { }

대괄호([ ]) 안에 HTML 속성과 값을 지정하여 해당 속성을 가진 요소를 선택합니다. [type="text"]처럼 정확한 값 매칭 외에도 [href^="https"](시작값), [src$=".png"](끝값), [class*="btn"](포함)처럼 다양한 패턴으로 활용할 수 있습니다.

[attr="value"] [attr^="시작"] [attr$="끝"] [attr*="포함"]
style.css 
/* 속성 선택자: 속성값에 따라 다른 스타일 */
input[type="text"] {
  border: 2px solid #2a6496; /* 파란 테두리 */
}

input[type="email"] {
  border: 2px solid #388e3c; /* 초록 테두리 */
}

input[type="password"] {
  border: 2px solid #c84b2f; /* 빨간 테두리 */
}
미리보기
text → 파란 테두리 email → 초록 테두리 password → 빨간 테두리
06

의사 클래스 선택자

요소:pseudo-class { }

콜론(:)을 사용하며, 요소의 특정 상태나 위치를 선택합니다. 사용자 인터랙션 상태(:hover, :focus, :active)나 구조적 위치(:first-child, :last-child, :nth-child(n))를 기반으로 동적 스타일을 적용할 수 있어 JavaScript 없이도 인터랙션 구현이 가능합니다.

:hover :first-child :last-child :nth-child(n) :focus
style.css 
/* 의사 클래스 선택자: 상태/위치 기반 */
li:first-child {
  background: #fff3e0;
  color: #e65100;
  font-weight: bold;
}

li:last-child {
  background: #e8f5e9;
  color: #2e7d32;
}

li:nth-child(even) { background: #f5f5f5; }

li:hover {
  background: #e3f2fd;
  padding-left: 22px;
  transition: all 0.2s;
}
미리보기 (항목에 마우스를 올려보세요)

  • 세 번째 항목 (:nth-child(even) — 회색 배경)
  • 네 번째 항목
  • 다섯 번째 항목 (:nth-child(odd))
  • 🏁 마지막 항목 (:last-child) — 초록색 강조
